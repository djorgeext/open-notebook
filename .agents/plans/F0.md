## Risks

- KV ≈ 7-8 GiB: 65536 ctx × 8 seqs may not fit → vLLM start error "max_model_len too big for KV" → drop LLM_MAX_LEN 32768 or LLM_MAX_SEQS 4.
- App switch to `large_context_model` at >105k tokens, but LLM_MAX_LEN 64k → big source fail with context error. Known limit; later features chunk/map-reduce.
- Download 52 GB slow → do before `stack.sh up`.
- Speaches master unpinned; onnxruntime-gpu on non-CUDA box → swap to onnxruntime CPU.
- Kokoro voice `alloy` maybe unknown → model test TTS fail; podcast (C9) need speaker profiles with Kokoro voices — F1.
- Port move diverge from upstream default (8000). Only ops/ + .claude docs change; app reads SURREAL_URL from `.env`. If user later frees 8000/8001 (their call, needs user ok to stop those procs), revert env.sh defaults.
